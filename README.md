# 🌌 AGI-Agent

**Минимальный обучающийся агент для RGB-пазлов**

![Python](https://img.shields.io/badge/python-3.10%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)

AGI-Agent — простой и расширяемый каркас обучающегося агента. Он живёт в сетке 3×3, двигает курсор, переставляет объекты `R`, `G`, `B`, пытается собрать правильный порядок и учится на основе получаемой награды.

Проект задуман так, чтобы его было легко понять и людям, и разработчикам, и LLM-моделям (Claude, Copilot, GPT).

## 🚀 Быстрый старт

### Требования

- Python 3.10+
- Внешние зависимости не нужны

### Запуск

Все команды выполняются из корня проекта.

Один эпизод:

```bash
python main.py
```

Бесконечное обучение (память и веса сохраняются между эпизодами):

```bash
python main.py while
```

Для остановки нажмите `Ctrl+C`.

## 🧠 Как работает агент

Цикл одного шага выглядит так:

```text
Состояние → Признаки → Гипотезы → Решение → Действие → Награда → Обучение → Память
```

### 1. Среда — `core/environment.py`

Агент действует в сетке 3×3. Пример начального состояния:

```text
G . .
. B .
. . R
```

Цель — собрать в первой строке:

```text
R G B
```

Доступные действия:

| Действие | Описание                               |
|----------|----------------------------------------|
| `move`   | перемещение курсора на соседнюю клетку |
| `swap`   | обмен содержимого клеток               |

### 2. Признаки — `core/features.py`

Из состояния среды извлекается вектор признаков:

| Признак         | Значение                                              |
|-----------------|-------------------------------------------------------|
| `mismatch`      | число позиций первой строки, не совпадающих с целью   |
| `dist_center`   | расстояние курсора до центра                          |
| `actions_count` | количество доступных действий                         |
| `objects_count` | количество объектов R/G/B на поле                     |
| `empty_cells`   | количество пустых клеток                              |

### 3. Гипотезы — `core/hypotheses.py`

Гипотеза — это намерение агента. Возможные варианты:

- найти `R` и поставить на позицию 0;
- найти `G` и поставить на позицию 1;
- найти `B` и поставить на позицию 2;
- исследовать среду (`explore`).

Гипотеза превращается в конкретное действие по правилу:

1. курсор не на объекте — двигаться к объекту;
2. курсор на объекте — двигаться к целевой позиции;
3. курсор на целевой позиции — выполнить `swap`.

### 4. Решение — `core/decision.py`

- если `mismatch > 0`, выбирается гипотеза `place_object`;
- иначе выбирается `explore`.

### 5. Действия — `core/actions.py`

- `move_cursor_towards` — шаг курсора в сторону цели;
- `execute` — применение действия к среде.

### 6. Обучение — `core/learning.py`

Веса обновляются по простому правилу:

```text
w_new = w_old + lr * reward * feature
```

где `lr` — скорость обучения, `reward` — награда за шаг, `feature` — значение соответствующего признака.

### 7. Оценка — `core/agi_score.py`

Метрика учитывает сумму наград и долю шагов с положительной наградой:

```text
AGI Score = reward_score + rule_discovery * 10
```

### 8. Память — `memory/memory.py`

Всё хранится в JSON-файлах в папке `memory/`: текущее состояние, история шагов, найденные правила, успешные состояния и веса. Чтобы начать обучение с нуля, достаточно очистить или удалить эти файлы.

## 🤖 Работа с LLM

Код разбит на небольшие модули с одной ответственностью, поэтому LLM-модели могут:

- читать и анализировать код по отдельным файлам;
- разбирать память агента в JSON;
- понимать и улучшать логику гипотез;
- добавлять новые типы задач и способы обучения.
