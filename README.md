# 🌌 AGI-Agent

**Самообучающийся агент для RGB-пазлов (Q-learning, без подсказок)**

![Python](https://img.shields.io/badge/python-3.10%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)

AGI-Agent — простой обучающийся агент. Он живёт в сетке 3×3, двигает курсор,
меняет местами клетки и пытается собрать объекты `R`, `G`, `B` в заданном
порядке. Главное: **агенту не зашита стратегия решения.** Он не знает заранее,
что и куда двигать. Он учится сам, методом проб и ошибок, по награде — как
именно решать пазл, он открывает самостоятельно (алгоритм Q-learning).

Проект сделан так, чтобы его было легко понять и людям, и разработчикам, и
LLM-моделям (Claude, Copilot, GPT).

## 🚀 Быстрый старт

### Требования

- Python 3.10+
- Внешних зависимостей нет (`tkinter` входит в стандартную библиотеку Python)

### Запуск

Все команды выполняются из корня проекта.

**Демонстрация** — агент уже обучен и решает случайные незнакомые расстановки:

```bash
python main.py
```

**Обучение с нуля** — агент стартует, ничего не зная, и на глазах умнеет
(кривая обучения в окне падает):

```bash
python main.py learn
```

**Бесконечное обучение** с показом каждого шага:

```bash
python main.py while
```

Для остановки нажмите `Ctrl+C`.

## 🧠 Как агент учится сам

Ключевая идея: **человек не задаёт стратегию.** Агент получает только:

1. **восприятие** — что сейчас на поле и где курсор;
2. **набор действий** — двигать курсор в 4 стороны и менять местами
   курсорную клетку с соседней;
3. **награду** — сколько объектов встало на свои места.

Как из этого получить решение — агент выясняет сам.

### Среда — `core/environment.py`

Сетка 3×3. Цель всегда одна — собрать в первой строке `R G B`. Но при каждом
эпизоде объекты и стартовая позиция курсора расставляются случайно, поэтому
агент постоянно попадает в незнакомые ситуации. Пример:

```text
G . .
. B .
. . R
```

### Q-обучение — `core/qlearning.py`

Агент хранит таблицу ценностей `Q(состояние, действие)` — насколько выгодно
сделать данное действие в данном состоянии. Обновление после каждого шага:

```text
Q(s, a) ← Q(s, a) + α · (r + γ · max Q(s', a') − Q(s, a))
```

- `α` — скорость обучения;
- `γ` — насколько ценим будущую награду;
- `r` — награда за шаг;
- `max Q(s', a')` — лучшая ожидаемая ценность из нового состояния.

Выбор действия — **ε-жадный**: с вероятностью `ε` агент пробует случайное
действие (исследование), иначе выбирает лучшее из известных (использование).
`ε` со временем падает: сначала агент много экспериментирует, потом действует
всё увереннее. Именно так он сам, без подсказок, находит стратегию «подвести
объект к его месту и поставить».

### Награда

```text
r = (стало верных клеток − было верных клеток) − 0.02  (+1.0 за полное решение)
```

Верно поставил объект — плюс; сломал уже собранное — минус; лишний шаг — мелкий
штраф. Больше агенту ничего не сообщают.

## 📊 Окно статистики

При запуске открывается окно (`stats_window.py`, на базе встроенного `tkinter`)
с русскоязычной статистикой: номер эпизода, размер поля и цель, число шагов на
решение (и сколько было в начале), доля исследования (случайных ходов), сколько
состояний агент уже изучил, и **график кривой обучения**. Чем ниже опускается
линия — тем быстрее агент решает пазл, то есть тем лучше он научился сам.

Если графическая среда недоступна, окно просто не открывается, а работа
продолжается в консоли.

## 🎯 Почему поле 3×3

Табличное Q-обучение запоминает каждое состояние поля отдельно. На 3×3 таких
состояний тысячи — их реально выучить, и агент честно осваивает задачу сам.
На больших полях (5×5, 6×6) число состояний астрономически велико: агент почти
никогда не попадает дважды в одну ситуацию и не может обучиться таблицей. Чтобы
работать с большими полями, нужен другой метод (нейросеть-аппроксиматор) — это
уже следующий уровень сложности.

При этом даже на 3×3 случайная расстановка даёт сотни разных стартовых позиций:
агент учится на одних, а решает те, которых конкретно не видел.
